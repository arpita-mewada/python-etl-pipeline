# Python ETL Pipeline

A simple Python-based ETL pipeline that ingests structured data (CSV/JSON),
cleans and transforms it using Pandas, and loads it into a SQL database
for analytical use cases.

## Tech Stack
- Python
- Pandas
- SQL (MySQL / PostgreSQL)
- CSV, JSON

## Pipeline Overview
1. **Extract**: Read raw CSV and JSON files.
2. **Transform**: Clean missing values, normalize columns, and apply basic transformations.
3. **Load**: Store processed data into a SQL database table.
